08 — Key Findings & Recommendations

What This Means & Next Steps

Actionable insights derived from the duplicate analysis across both Temenos test scenario datasets.

🚨
SY Account File is Most Critical
With a 57.3% duplication rate, more than half of SY_ACC contains repeated descriptions. "EN 1426890" alone appears 21 times — an entire test group bulk-copied without updating the description field. Immediate cleanup is required.
⚠️
MM File Has the Widest Spread
With 46 unique duplicate groups, the MM file's duplication is far broader. The top 3 descriptions each appear 10 times and all relate to TEST BASE MERGER scenarios — suggesting bulk copy-paste during test creation cycles.
🔍
Naming Inconsistency Hides More Duplicates
"EN 1388099" (space) and "EN-1388099" (hyphen) reference the same enhancement but are stored as different values — creating 11 hidden duplicates. A fuzzy-match or normalization pass would surface even more cross-file overlap.
✅
Recommended Actions
1. Enforce unique description constraint at data entry.
2. Standardize to EN-XXXXXXX naming format.
3. Review MM's 46 dup groups — verify if SCENARIO.IDs truly differ.
4. Prioritize SY_ACC cleanup due to 57% severity rate.
5. Automate a weekly duplicate scan on both files.
